歡迎來到 Niugnep 的部落格

這裡是 Niugnep，一個國二升國三的傢伙。
以下簡單講講這個網站的幾個區域：

文章(/posts/*)

我現在已經很少用 Facebook 等社群平台了，主要的文章都在這裡。
這裡放的是大長篇為主，愛寫什麼寫什麼，也就是我幹話的地方啦。

不過，由於此站點的主畫面也改成了一篇文章，所以麻煩到所有文章啦！
或者，在這邊隨機抽一篇文章。

時間軸(/timeline)

這個比較神奇，其實是類似動態牆的東西。
裡面會塞很多以短部落格呈現的生活瑣事、幹話、抱怨等。
會比較出言不遜，看到不爽不要找我哀喔awa

其他的頁面(/spec/*)

  • 關於我：介紹我本人的狀況
  • 裝備欄：介紹我目前使用的軟體等
  • 我推的站點：即Blogroll，會有我推薦的部落格

開發中

  • 相簿：會放一些能公開放的圖片
  • 近況：即/now頁面，我也會乖乖叫/spec/now.html，不亂取好吧
  • 筆記：預計單獨開一個新倉庫寫

注意事項

  • 這個部落格有留言區，但屬性依然偏向我愛寫什麼寫什麼，不要圍剿我——應該說你在別人地盤號召打第主幹嘛
  • 留言區用的是Giscus，因此要留言請用GitHub登入
  • 部份文章比較偏激，我會加上警告，看不下去就趕緊離開！
